# Working on this live product

- When fixing an issue, inspect the complete affected user journey and all sibling features that could share the same defect. Do not stop at the first occurrence.
- Check related links, signed-in and signed-out behavior, error states, and downstream actions as applicable. Add meaningful regression coverage for functional bugs.
- Report what was verified, remaining limitations, and whether changes are local or deployed. Never imply a live fix without deployment evidence.

- Generated business briefs, planning templates and tool results must use the shared printer-style SummaryPreview flow before printing or saving. Reuse the global preview host; do not add page-level duplicates or direct text-file downloads. Preserve purpose-built downloads for original files, CVs, certificates and other finished documents.
- Homepage interactions must address real user tasks and retain entered work while switching sections. Use explicit service labels (for instance, “Build my website”), grounded claims and customer-facing language.
